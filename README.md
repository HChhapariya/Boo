# Boo 💕

A romantic, interactive Valentine's Day proposal web application.

## Features

- 💖 Beautiful glassmorphism design with romantic gradient background
- 🐻 Cute bear mascot with animated floating hearts
- 🎯 Interactive "runaway" No button that's impossible to click
- 🎉 Confetti celebration when YES is clicked
- 📱 Fully responsive - works on mobile and desktop
- ✨ Smooth animations and transitions

## How to Use

Simply open `index.html` in any modern web browser. No build process or installation required!

```bash
# Clone the repository
git clone https://github.com/HChhapariya/Boo.git

# Open the file
cd Boo
open index.html  # macOS
# or
start index.html  # Windows
# or
xdg-open index.html  # Linux
```

Or just double-click the `index.html` file to open it in your default browser.

## Technical Stack

- **HTML5**: Semantic structure
- **Tailwind CSS**: Via CDN for styling
- **Google Fonts**: Pacifico (cursive) and Quicksand (body text)
- **Vanilla JavaScript**: For all interactions and animations
- **HTML5 Canvas**: For confetti particle system

## Browser Support

Works in all modern browsers that support ES6 JavaScript and HTML5 Canvas:
- Chrome/Edge 60+
- Firefox 55+
- Safari 11+
- Opera 47+
